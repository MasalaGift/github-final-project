# Simple Interest Calculator

This project contains a simple shell script that calculates simple interest.

## Purpose

The purpose of this project is to provide a simple tool that can be used to calculate interest based on a principal amount, rate of interest, and time period.

## Formula Used

Simple Interest = (P × T × R) / 100

Where:

* P = Principal Amount
* T = Time Period
* R = Rate of Interest

## How to Run

1. Clone the repository.
2. Open a terminal in the project directory.
3. Run the script:

```bash
bash simple-interest.sh
```
